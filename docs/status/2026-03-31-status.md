# Bubble Bolt – Status (2026-03-31)

## TL;DR
- Play-from-blank now works: drop the new **PrototypeSceneBootstrap** prefab into an empty scene and you instantly get the full greybox loop (player orbit, rival ghost, hazards, HUD, match flow).
- HUD + Overcharge button are live and data-driven, so the prototype finally reports combo/score/lives/coverage in real time and enforces gauge gating on the CTA.
- Hazard arcs are implemented with deterministic radius/angle checks plus cooldowns, so the punishment loop is functional while we still use placeholder visuals.
- README + scene checklist now document both the Unity 2022.3 setup and the "inspect with Unity 6.4" path for bleeding-edge editor tests.

## Delivered This Update
1. **Runtime bootstrap helper** (`unity/Assets/Scripts/Systems/PrototypeSceneBootstrap.cs` + prefab)
   - Instantiates tuning data, creates arena/player/rival GameObjects, spawns equidistant hazards with gizmo markers, wires MatchState + PlayerPainter + rival AI, and optionally builds a temp HUD/event system.
   - Early-out guard prevents double-instantiating if a handcrafted scene already owns the required components.
2. **HUD + CTA wiring** (`UI/HudTelemetry.cs`, `UI/OverchargeButton.cs`)
   - Telemetry now mirrors combo multiplier, score, lives (● glyphs), and dual coverage sliders straight from gameplay data each frame.
   - Overcharge button visualizes gauge fill, changes color when armed, and only triggers when the gauge is full and no Overcharge is active.
3. **Arena hazard gameplay pass** (`Gameplay/Arena/ArenaHazard.cs`)
   - Hazards track the player’s polar coordinates, ignore hits while Overcharge is active, and expose UnityEvents for juice hooks.
   - Configurable arc width, radius tolerance, and cooldown make it easy to author different trap flavors later.
4. **Documentation**
   - `docs/prototype-scene-checklist.md` now walks anyone through the first-playable hierarchy + wiring order + definition of done.
   - README describes how to duplicate the project for Unity 6.4 inspection, required packages, and upgrade caveats.

## Testing / Validation
- Manual Play Mode smoke tests in Unity 2022.3 confirm the bootstrapper scene builds cleanly, hazards trigger life loss, and UI reflects state changes.
- Device Simulator (iPhone 15 Pro preset) used to validate swipe orbiting + Overcharge CTA with touch input.
- No automated tests yet; coverage will come once we have deterministic gameplay services.
